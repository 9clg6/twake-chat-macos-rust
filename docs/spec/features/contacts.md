## Acceptance criteria (from e2e test bodies)

### e2eA: Activity

- [chat.e2e.ts] Given a mention by Bob When `nav-activity` clicked Then `activity-mention` row containing the text shows; clicking opens the room timeline with the text.

### e2eB: contacts

- [contacts] Given the Contacts tab When opened Then rows (testid contact) of the address book, never the user themself; search keeps matches with typed letters bold (highlight); opening a contact opens the DM and nav-chat gets aria-current page; empty state shows the illustration
- [contacts] Given the tabs of the left column When measured Then Chats, Contacts, Activity share title position, row heights [22, 56, 48] (title, row, avatar) and a name typed in lower case shows capitalised (D205, D209); header does not jump between tabs
- [contacts] Given a profile of a non-contact When "Add to contacts" Then toast containing "added to your contacts", button toggles to "Remove from contacts" and back to "Add to contacts"; the address book at ToM updates
- [contacts] Given invitations sent When listed Then row shows "Pending"; ToM sends an e-mail matching /alice... has invited you/i with invitation_token link
- [contacts] Given the room list search When typed Then people of the directory under the rooms (D147), pick opens the DM and clears the search; Spotchat from the Contacts tab (switcher-input)
- [contacts] Given "+" add contact When Matrix id and name entered Then save disabled until valid (id grammar checked as typed; "name:server" gets "@"; "enter an id like" hint), toast bottom centre of the main pane (offCentre < 2 px, fromBottom < 120 px, D273) with a close button; share icon opens invite-dialog with personal link (invite-link), QR code decoding to the link, copy button ("Copied" or browser refused), one X close (accessible name "Close" count 1, no text Close button)
- [contacts] Given a contact whose Matrix id nobody holds When opened Then a toast within seconds, other rows stay enabled; on the Create page the error "no account answers" appears at the top above the search; list never frozen
- [contacts] Given a people search When one letter Then no "nobody" message; after >= 2 letters and the directory's answer "no match" appears; Contacts tab searched says "No contact matches." never "No contacts yet."; id under the name on one line, match in accent colour
- [contacts] Given the room list When it loads Then it does not read the whole address book (0 fetches), only search of everything does; new messages do not refetch it
- [contacts] Given a DM info card When opened Then e-mail Bob shared since is shown (re-read when card opens); a contact renamed from DM info keeps that name there, in the room list (D302), in "@" suggestions (find by new or Matrix name), message text uses the Matrix name ("bob "), pill opens profile (?user=) with heading = given name and profile-edit
- [contacts-visibility] Given Settings profile When toggling Then visibility-private / visibility-contacts radios write to ToM ("private", "contacts") and read back (D78)
- [activity-row-aligned] Given an Activity row When compared with a Contacts row Then same avatar, name and secondary line metrics in both themes
