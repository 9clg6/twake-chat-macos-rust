### e2eA: Composer

- [chat.e2e.ts] Given the composer Then the reply banner sits inside the field (within its border) and has rounded corners on all four (D276).
- [chat.e2e.ts] Given the composer empty Then a mic (`composer-voice`) shows; at the first typed letter a round send arrow (`composer-send`/`composer-round-icon`) replaces it; emptied again the mic returns.
- [chat.e2e.ts] Given the message field Then attach left/top/bottom and last-button top/bottom/right gaps to the pill are all equal; pill border-radius 22px; send/mic button border-radius 50%; composer padding 16px; 8px between pill right edge and round button; pill height equals round button height (D167, D181).
- [chat.e2e.ts] Given 3 lines typed ("one\ntwo\nthree") Then the field grows upwards (taller), buttons stay at the bottom with same bottom gaps.
- [chat.e2e.ts] Given the composer grows Then a timeline at the bottom stays at the bottom (0 px from bottom).
- [chat.e2e.ts] Given text "Salut :smi" When the user types ":smi" Then `emoji-suggestions` list shows; Escape closes it and keeps text "Salut :smi"; with a fresh ":smi", second option contains ":smile:", ArrowDown selects it (aria-selected true), Enter replaces the name with "😄" ("Salut <stamp> 😄") and closes the list; next Enter sends the message.
- [chat.e2e.ts] Given the emoji button When clicked Then picker opens; "Insert 😀" ArrowRight moves focus to "Insert 😃", Enter inserts ("Yes 😃"). Full picker holds the full set (>500 emojis, not 64), keeps the height it opened with, stays inside the window (bottom <= innerHeight); searching "croissant" shows "Insert 🥐", ArrowDown from the field enters results, Enter inserts "🥐"; search "qqqzzz" shows `emoji-empty`.
- [chat.e2e.ts] Given "@bo" typed Then `mention-suggestion` contains "bob"; Enter inserts "bob " (name kept in text); sent message renders "bob" as a link to https://matrix.to/#/%40bob%3Alocalhost. Same inside a thread panel. "@@bob:localhost" (full Matrix id) also lists bob.
- [chat.e2e.ts] Given a message sent as "**bold X** and `code`" Then the message aria-label contains ", bold X and code, " (Markdown stripped).
- [chat.e2e.ts] Given "/foo bar" (unknown command) When Enter Then an alert "This command does not exist" shows and the text stays "/foo bar"; "//foo bar" sends "/foo bar".
- [chat.e2e.ts] Given a bot with commands help ("What I can do") and "leave {days} {reason...}" ("Ask for days off") announced, bob being the user's assistant When "/le" typed Then `command-suggestion` contains "Ask for days off"; Enter inserts "/leave "; sending "/leave 2 dentist X" shows "!leave 2 dentist X" and sends body "!leave 2 dentist X" with `org.matrix.msc4332.command` {syntax 'leave {days} {reason...}', arguments {days:'2','reason...':['dentist',X]}}.
- [chat.e2e.ts] Given a bot that is neither the user's assistant nor the platform creator When "/de" typed Then no `command-suggestion` (D27). Given the creator id configured (ASSISTANT_CREATOR_USER_ID) Then "/de" offers "delete your assistant", Enter gives "/delete ", sent as body "!delete" with MSC4332 syntax 'delete' (D151).
