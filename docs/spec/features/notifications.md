## Acceptance criteria (from e2e test bodies)

### e2eB: notifications

- [notifications] Given browser notifications on by default When first user action Then the browser asks permission and a web pusher is created with format "full", events_only true, endpoint of the subscription, default_payload show_text true and encrypted_body "You have an encrypted message"; settings show browser-notifications checked and closed-tab-notifications text containing "also arrive when Twake Chat is closed"; turning off removes the pusher
- [notifications] Given a message in another room When it arrives Then a notification with author and room name, click opens that room; the room on screen is not notified; with "Mentions only" a plain message is silent and a mention notifies
- [notification-rules] Given switches for notices and member events When toggled Then they write push rules (notices off by default, invitations on); an assistant bring-in request has its own push rule (its state event matches no default)
