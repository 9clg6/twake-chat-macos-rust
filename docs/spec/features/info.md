## Acceptance criteria (from e2e test bodies)

### e2eA: Room header / info panel

- [chat.e2e.ts] Given a room opened When no info is requested Then the conversation shows alone (`info-panel` count 0); the header title is a button named by the room name ("Child project 1") whose aria-describedby text is "Show room info"; no "i" button (D75).
- [chat.e2e.ts] Given the room header When the title button is pressed Then the info panel opens beside the conversation, timeline stays visible (D192), panel shows the room topic ("Everything about project 1") and a button named "Hide room info".
- [chat.e2e.ts] Given no identity change When info is open Then no `identity-line` and no text matching /has new security keys/.
- [chat.e2e.ts] Given a room header When another member types Then the subtitle (normally matches /members?/) reads exactly "bob is typing…" (within 30 s) and no typing band exists above the composer.
- [chat.e2e.ts] Given a bot-announcing member (bob) When viewed Then his messages carry a "Bot" label; info panel for a 2-person room contains "2 members"; his profile panel (opened by clicking message-author) has a `bot-badge` containing "Bot".
- [chat.e2e.ts] Given the room list out of a call Then no `fold-list` button exists.
- [chat.e2e.ts] Given a room Then the screen has: messages in bubbles, a thread preview card (with count) under a message, a text field at the bottom, a header with room name and member count.

### e2eA: Profile panel

- [chat.e2e.ts] Given a group room When button "View the profile of bob" clicked Then `profile-panel` contains "@bob:localhost", "Role" (group only, read only), heading "bob", button "Close", tiles `profile-message` "Message", `profile-search` "Search", `profile-more`; Mention (`profile-mention`) under More puts "bob " in composer; E-mail (`profile-email`) under More opens mailto:bob@twake.test (via window.open); Search opens the direct room's search (`room-search` visible, profile panel closed).
- [chat.e2e.ts] Given the profile within an existing direct room (?user=@bob:localhost) Then tiles Video (`profile-video`), More, Search show; no `profile-message`, no Role (D355), no `profile-mention` (D197); `profile-email-send` button sits in the right half of the panel; `start-call` button in the header is left of `header-search` (D197). Info panel of the direct room offers `info-more` > `info-email`.
- [chat.e2e.ts] Given a person who shares their e-mail later Then reopening the profile (after Close) shows `copy-email` and More offers `profile-email`.

### e2eA: Room settings / notifications

- [chat.e2e.ts] Given room info When shown Then no `info-message` tile beside the conversation (D225); tiles `info-video` "Video", `info-search` "Search", `info-more` "More" (D188); More tile wider than 15% of panel width. More holds notification levels (`level-mentions` aria-checked true after selection; Escape closes).
- [chat.e2e.ts] Given settings > notifications (`open-notifications`) Then `groups-mentions` and `groups-all` radios are checked after click; `notification-sound` switch persists on this device after leaving and returning (via `nav-chat`); a new device has it on (D240).
- [chat.e2e.ts] Given a room with level mentions only When 2 messages arrive and the room is not open Then its `unread-badge` reads "2" (grey count); opening the room removes it.

### e2eA: Info pane layout

- [side-pane-layout.e2e.ts] Given 1280x720 Then `info-panel` width = 360 px, sits beside the timeline (panel.x >= timeline right - 1), timeline width >= 360.
- [side-pane-layout.e2e.ts] Given 1024x768 Then `info-panel` width = 360 px, floats over the conversation flush with the right edge (x + width = 1024); Escape closes it (D220).
