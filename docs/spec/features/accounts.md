## Final behaviours (4 entries)

- **D373** [accounts] replaces: D19,D124 (updates) | final: Up to 5 Matrix accounts at once, any homeserver(s), each signed in via its `/login` flows (SSO providers in popup, one button per provider; password form when offered). No account privileged: each gets services its own well-known declares; first signed in is default; page reopens on the account last on screen. Deployment services (Twake SSO, bar, Drive, Mail, scribe, analytics, GIF proxy, public pages) go to the first account of the configured homeserver only. One account on screen: app-bar account menu lists accounts with what waits in each + "Add an account"; Settings "Accounts" section (open, add, sign out of this one / of all). Others keep syncing, joining invites, notifying, ringing; click on their notification/ring switches to that account at the room. Chat badge, tab title, icon count all accounts. No account in URL (notification adds `?account=` read once). Add dialog takes server name, address or user id; already-added refused; second account on same IdP -> dialog points to password. One call per device across accounts. Push: pusher `append: true`, `user_id` in `default_payload`. Inside Twake Space the frame shows the configured-homeserver account only. — *modified by: D395, D396*
- **D381** [accounts] replaces: D210 (follows) | final: Adding an account on a server the installation's CSP blocks says "This installation of Twake Chat does not allow this server" (vs "No Matrix server answers at this address"); check waits 250 ms for the CSP violation report on a failure. Only relevant if deployment narrows policy (see D385).
- **D395** [accounts] replaces: D373 (security follow-up) | final: Adding an account first tries `claimLoginToken` on the deployment: a token it accepts is the main account's, so the new device is signed out and dialog says so (`sign_in_hijacked`); any answer but 403 stops sign-in. Added accounts return on `/accounts/callback`. User id answered by an added server must be its own (`servesUser`, `account_mismatch`). An account already running in another tab joins that session. Popup has no opener; web push goes to deployment accounts only; discovery gives up after 10 s. — *modified by: D396*
- **D396** [accounts] replaces: D373,D395 (follows) | final: Account fixes: a 401 forgets a session, 429/5xx/network loss keeps it. Notice of an account the server ended has an "Add it again" button opening add-account dialog on its user id (reuses device). Accounts of other homeservers stay stored and start again after sign-in at the deployment. Twake Space serves the active account if of the configured homeserver else the first. Declined calls, folded spaces/sections, answered questions kept per account. Drafts stay per tab. — *modified by: D512*
