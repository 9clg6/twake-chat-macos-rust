## Acceptance criteria (from e2e test bodies)

### e2eB: status

- [status] Given a profile of bob with a status When opened Then profile-status shows the text; the DM header shows "status · presence" on one line (status-line-status then status-line-presence), presence dot on avatar hidden from readers; DM info never says "2 members"; Message tile icon same size as other tiles (D466)
- [status] Given status changes while profile open Then updated by polling (every 15 s focused, 1 min unfocused, D474); presence "Online" (profile-presence) stays while messages arrive (D531)
- [status] Given the account menu When status set Then status-field value sent as status_msg, cleared gives ''; max length 60 (maxlength attr "60") with counter "60/60"; a 100-char no-space status from another client stays inside the profile
- [status] Given presets When listed Then dots green, orange, red, grey (choice-dot-*) and a beach emoji 🏖️ for "On holiday"; status-preset-dnd/away/vacation radios exclusive; "Do not disturb" preset turns the Settings DND switch on (D439)
- [status] Given a group When messages shown Then avatar carries presence dot (data-state "online"); in a run of messages the name stands on the first, the avatar (and presence dot) on the last, nothing between (D500); in DMs the last of a run has avatar and tail (bubble-tail count 1), the first has none (D519)

### e2eC: Polls

- [polls] Given composer-attach (the "+") > `composer-poll` Then fields `poll-question`, `poll-answer-field` (2 first, `poll-add-answer` adds more), checkboxes `poll-multiple`, `poll-anonymous`, `poll-submit` (MSC3381, D54).
- [polls] Given a 3-answer poll Then 3 `poll-answer`; after bob votes `poll-summary` text "1 vote"; alice votes: "2 votes" and her answer `aria-pressed="true"`; `poll-end` + `confirm` gives "Poll ended · 2 votes" and no `poll-end`; the room row `room-preview` shows the question.
- [polls] Given a multiple poll Then summary "Several answers allowed · 1 vote" after picking two; clicking a picked answer again sets it `aria-pressed="false"`, the other stays.
- [polls] Given the author (D414) Then the message menu has `message-edit` which opens the same form filled (`poll-question` has the question); until someone votes; after a vote `message-edit` and `message-forward` are absent (D413).
- [polls] Given a channel of a space Then it takes a poll; the space itself is no conversation (D170).
- [polls] Given a poll in an older broadcast channel Then a moderator's poll lets members vote; a member sees another's poll with answers disabled and the text "Only the people who may post here can vote."
- [polls] Given non-anonymous poll Then `poll-voters` shows beside votes (count 1); anonymous: counts show ("1 vote") and `poll-voters` count 0; the owner may not end someone else's poll (`poll-end` count 0).
- [polls] Given a 360 px viewport Then a poll with a very long answer stays inside its bubble (overflow <= 0 px).
- [polls] Given a new poll Then question and each answer stop at 150 characters (200 typed gives 150) and the counter "150/150" shows.
- [polls] Given a very long answer from another client Then its button height is under 120 px (three lines).
