# API sketch required by the token generator tests

Written by the test author from the need, before the production code exists. The need:
`ARCHITECTURE.md` section 3 (`twake-tokens`: generated from `docs/spec/tokens.json`, no GPUI,
no dependency, optional `serde` only; rule 3, A011/Q7), `docs/spec/design-system.md` section 4
("generated file deterministic and checked in CI: `cargo xtask tokens --check`").
The `twake-tokens` half was checked against a throw-away reference (generated by a script
from the real `tokens.json`): its 34 tests pass. The `tokens_generate` half (23 tests) passed
against a throw-away `generate`. The CLI and `tokens_repo` tests are red until the real code exists.

Tests: `crates/twake-tokens/tests/color.rs`, `crates/twake-tokens/tests/generated.rs`,
`xtask/tests/tokens_generate.rs`, `xtask/tests/tokens_cli.rs`, `xtask/tests/tokens_repo.rs`.
Dev-dependency added: `serde_json = "1"` in `twake-tokens` (reads `tokens.json` at run time;
dev-dependencies do not count against rule 3, A011/Q7: P8 asks for a line in `decisions.md`).
`xtask` needs `serde_json` as a normal dependency to implement the generator (also a line in
`decisions.md`; it already comes through `cargo_metadata`).

## 1. `twake-tokens` (hand-written `lib.rs`, plus `generated.rs` re-exported at the root)

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub struct Rgba8 { pub r: u8, pub g: u8, pub b: u8, pub a: u8 }
impl Rgba8 {
    pub const fn new(r: u8, g: u8, b: u8, a: u8) -> Self;
    pub const fn rgb(packed: u32) -> Self;                       // 0xRRGGBB, opaque
    pub const fn from_hex(text: &str) -> Result<Self, ParseColorError>; // const fn
}
// "#rgb" (each digit doubled), "#rrggbb" (opaque), "#rrggbbaa"; case-insensitive.
// Refused (Err, never a panic): no '#', any other length, non-hex digit, whitespace,
// multi-byte characters, "rgba(...)" and colour names.

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct ParseColorError;            // + Display + std::error::Error

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Palette { pub shades: [Rgba8; 10], pub contrast_text: Option<Rgba8> }
impl Palette { pub const fn shade(&self, n: u16) -> Option<Rgba8>; } // 50,100..900 else None
// shades[0] = 50 ... shades[9] = 900

pub struct Tone { pub light: Rgba8, pub main: Rgba8, pub dark: Rgba8, pub contrast_text: Rgba8 }
pub struct TextColors { pub primary: Rgba8, pub secondary: Rgba8, pub disabled: Rgba8, pub icon: Rgba8 }
pub struct BackgroundColors { pub default: Rgba8, pub paper: Rgba8, pub contrast: Rgba8 }
pub struct BorderColors { pub main: Rgba8, pub disabled: Rgba8, pub ghost: Rgba8, pub ghost_disabled: Rgba8 }
pub struct Scheme {
    pub primary: Tone, pub secondary: Tone, pub error: Tone,
    pub warning: Tone, pub success: Tone, pub info: Tone,
    pub text: TextColors, pub background: BackgroundColors, pub border: BorderColors,
    pub divider: Rgba8,
}
#[derive(Debug, Clone, Copy, PartialEq)]
pub enum LineHeight { Ratio(f32), Px(f32) }
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct TypeSpec { pub font_size: f32, pub font_weight: u16, pub line_height: LineHeight, pub letter_spacing: f32 }
// all the structs: Debug, Clone, Copy, PartialEq (Eq where there is no float).
```

Generated constants (`pub const`, at the crate root):

| from `tokens.json` | constant |
|---|---|
| `paletteRaw.Primary` ... | `PRIMARY, SECONDARY, ERROR, WARNING, SUCCESS, INFO, GREY: Palette` (`ContrastText` absent -> `None`: Info, Grey) |
| `paletteRaw.Common` (`white`, `black`) | `WHITE`, `BLACK: Rgba8` (the CLI fixture does not cover them; `generated.rs` tests do) |
| `schemes.light.palette`, `schemes.dark.palette` | `LIGHT`, `DARK: Scheme` |
| `spacing.unit` (`var(--twake-spacing, 8px)`) | `SPACING: f32 = 8.0` |
| `shape.borderRadius` | `SHAPE_RADIUS: f32` |
| `radius.{none,sm,md,lg,pill}` | `RADIUS_NONE, RADIUS_SM, RADIUS_MD, RADIUS_LG, RADIUS_PILL: f32` (`"0"`, `"4px"`) |
| `breakpoints.{xs,sm,md,lg,xl}` | `BREAKPOINT_XS ... BREAKPOINT_XL: f32` |
| `typography.<style>` (not `inherit`) | `TYPE_H1..TYPE_H6, TYPE_SUBTITLE1, TYPE_SUBTITLE2, TYPE_BODY1, TYPE_BODY2, TYPE_BODY3, TYPE_BUTTON, TYPE_CAPTION, TYPE_OVERLINE: TypeSpec` |

Colour conversion: `#hex` as `from_hex`; `rgb(r, g, b)` and `rgba(r, g, b, a)` with
`a` in 0..=1 and the byte = `round(a * 255)` (0.64 -> 163, 0.12 -> 31, 0.16 -> 41, 1 -> 255).
Type: `lineHeight` number -> `Ratio`, `"13px"` string -> `Px(13.0)`; `letterSpacing` `"0.15px"` -> `0.15`,
absent -> `0.0`; `fontSize` number -> px.

## 2. `xtask::tokens` (library, module `xtask/src/tokens.rs`)

```rust
pub struct Error(String);              // Debug + PartialEq + Display (the message)
pub fn generate(json: &str) -> Result<String, Error>;
```

Output text (tests squash whitespace, so layout is free; the spellings below are exact):

- first line: ``// @generated by `cargo xtask tokens` from docs/spec/tokens.json (twake-mui <twakeMuiVersion>). Do not edit.``;
  ends with a newline.
- `pub const PRIMARY: Palette = ...` with `shades: [Rgba8::new(r, g, b, a), ...]` in order 50..900
  and `contrast_text: Some(Rgba8::new(..))` or `contrast_text: None`.
  Only the palettes present in `paletteRaw` are emitted; nothing is invented.
- `pub const LIGHT: Scheme`, then `pub const DARK: Scheme` (always that order).
- `pub const SPACING: f32 = 8.0;` (floats in Rust `Debug` spelling: `4.0`, `1.313`, `0.15`),
  `RADIUS_*`, `BREAKPOINT_*`, `SHAPE_RADIUS`, `TYPE_*: TypeSpec { font_size, font_weight, line_height, letter_spacing }`,
  `LineHeight::Ratio(1.313)` / `LineHeight::Px(13.0)`.
- Optional sections (`schemes`, `typography`, `spacing`, `shape`, `radius`, `breakpoints`): absent -> not emitted.
- Deterministic: same bytes for the same data, whatever the key order of the JSON objects.

Errors (`Error::to_string()` contains):
- not JSON, or empty: `invalid JSON`; JSON that is not an object: an error.
- no `paletteRaw`: `paletteRaw`; no `twakeMuiVersion`: `twakeMuiVersion`.
- a colour that does not parse: the offending text (e.g. `#12g`).
- a palette without one of its ten shades: the palette name and the shade (`Primary`, `600`).
- a scheme without a group (`divider`, `text`, `background`, `border`, a tone): its name.

## 3. `cargo xtask tokens [--input FILE] [--output FILE] [--check]`

Defaults: `docs/spec/tokens.json` -> `crates/twake-tokens/src/generated.rs`, resolved from the
workspace root (so it works from any directory).

| case | exit | effect |
|---|---|---|
| no `--check` | 0 | writes the output (overwrites a stale file), idempotent |
| `--check`, file equals `generate(json)` | 0 | nothing written |
| `--check`, file differs or is missing | 1 | nothing written; stderr says to run `cargo xtask tokens` |
| invalid JSON / bad token (with or without `--check`) | 2 | stderr has the `Error` message; nothing written |
| input file unreadable | 2 | stderr names the file |
| unknown flag | 2 | usage on stderr |

`tokens_repo.rs`: the committed `crates/twake-tokens/src/generated.rs` equals `generate` of the
committed `tokens.json` (so the implementer commits the generated file).
