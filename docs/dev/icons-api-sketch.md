# API sketch required by the icon generator tests

Written by the test author from the need, before the production code exists. The need:
`ARCHITECTURE.md` (`twake-icons`: the twake-icons SVG set as static data, no GPUI, no normal
dependency), the same generated-file contract as the tokens (`docs/dev/tokens-api-sketch.md`,
`cargo xtask icons --check` in CI). All the tests are red until the code exists (the `twake-icons`
and `xtask::icons` imports do not compile yet).

Tests: `crates/twake-icons/tests/icon.rs`, `crates/twake-icons/tests/generated.rs`,
`xtask/tests/icons_generate.rs`, `xtask/tests/icons_cli.rs`, `xtask/tests/icons_repo.rs`.
Dev-dependency: `serde_json = "1"` in `twake-icons` (reads `docs/spec/icons.json` at run time).

## Input `docs/spec/icons.json`

```json
{"source":"@linagora/twake-icons@3.0.0","icons":{"album-add":{"viewBox":"0 0 16 16","body":"<path d=\"...\"/>"}}}
```

- Ids are kebab-case: `[a-z0-9]+(-[a-z0-9]+)*`; anything else is an `Error` naming the id.
- `viewBox`: four numbers separated by spaces and/or commas (`min-x min-y width height`);
  width and height must be > 0. Else `Error` naming the id and the bad text.

## 1. `twake-icons` (hand-written `lib.rs`, `generated.rs` re-exported at the root)

```rust
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct ViewBox { pub min_x: f32, pub min_y: f32, pub width: f32, pub height: f32 }

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Icon { pub id: &'static str, pub view_box: ViewBox, pub body: &'static str }

impl Icon {
    /// Exactly: <svg xmlns="http://www.w3.org/2000/svg" viewBox="{min_x} {min_y} {width} {height}" fill="currentColor">{body}</svg>
    /// numbers in Rust `Display` spelling (`16`, `0.5`, `-1`); the body is not touched.
    pub fn to_svg(&self) -> String;
}
pub fn by_id(id: &str) -> Option<&'static Icon>;   // binary search on ALL; exact, case-sensitive
```

Generated (root of the crate): one `pub const NAME: Icon` per icon, and
`pub static ALL: &'static [Icon]` sorted by id (byte order), consts and `ALL` entries in that order,
`ALL` after the consts.

## 2. `xtask::icons` (library, module `xtask/src/icons.rs`)

```rust
pub struct Error(String);              // Debug + PartialEq + Display (the message)
pub fn generate(json: &str) -> Result<String, Error>;
```

Output (tests squash whitespace, so layout is free; the spellings below are exact):

- first line: ``// @generated by `cargo xtask icons` from docs/spec/icons.json (<source>). Do not edit.``;
  ends with a newline.
- `pub const ALBUM_ADD: Icon = Icon { id: "album-add", view_box: ViewBox { min_x: 0.0, min_y: 0.0, width: 16.0, height: 16.0 }, body: "..." };`
  floats in Rust `Debug` spelling (`16.0`, `20.5`, `-1.0`).
- `body` is a regular string literal: `\` becomes `\\`, `"` becomes `\"`, a newline `\n`. No raw string.
- Const name: id upper-cased, `-` becomes `_`. A name that starts with a digit, or is `ALL`
  (the static), gets the prefix `I_` (`3d-rotate` -> `I_3D_ROTATE`, `all` -> `I_ALL`).
  Two ids with the same name (`all` and `i-all`) -> `Error` naming both ids.
- `pub static ALL: &[Icon] = &[A_B, A1, ...];` sorted by id, not by name (`a-b` before `a1`).
  An empty `icons` object is valid (`ALL` is `&[]`).
- Deterministic: same bytes whatever the key order of the JSON objects.

Errors (`Error::to_string()` contains):
- not JSON, or empty: `invalid JSON`; JSON that is not an object: an error.
- no `source`: `source`; no `icons`: `icons`.
- an icon that is not an object, or without `viewBox` / `body` (string): the id and the key.
- a bad viewBox: the id and the offending text. A bad id: the id.

## 3. `cargo xtask icons [--input FILE] [--output FILE] [--check]`

Defaults: `docs/spec/icons.json` -> `crates/twake-icons/src/generated.rs`, from the workspace root.
Same table as tokens: 0 writes (idempotent) / `--check` up to date; 1 `--check` stale or missing
(stderr says to run `cargo xtask icons`, nothing written); 2 invalid input, unreadable input
(stderr names the file), unknown flag (stderr names it); nothing written on 2.

`icons_repo.rs`: the committed `crates/twake-icons/src/generated.rs` equals `generate` of the
committed `docs/spec/icons.json`.
